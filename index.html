かがり手まり 3D制作工程

①手まり芯、②地割り、③かがりを一続きで追い、針が右から入り球内へ潜って左へ抜ける動きと、糸の上下関係も確認できる単体HTMLです。

common display / 共通表示
針は表面の進行方向に対して右側から入り、球内へ潜って左側へ抜ける動きを表示します。Uwagake / Sakasa など原典で上下関係が明記される工程では、現在糸の深さも上／下に変化させます。
点・番号について 白丸は現在動いている糸先です。数字・英字は、参照元の図で指定された点番号を優先して表示します。原典に点名がない工程では、動きを追いやすくするための補助番号を表示する場合があります。3D上の位置は原典の順序・隣接関係を保ちながら球面へ相対座標化しているため、絶対寸法を示すものではありません。

かがり糸を個別指定（色・線種・太さ・素材）
1.0×
個別設定中です。共通の基本色・線種・太さ・リアリスティック素材は無効です。各糸に、共通設定と同じ4種類の線種と太さ・素材を個別指定してください。
画像未指定：内蔵の繊維テクスチャを使用

①芯の色、②地割り糸、③かがり糸を個別に設定できます。通常は共通の線種・太さが全かがり糸に適用されます。「リアリスティック3D」では10種の素材構造を選べます。「糸色を個別指定」では、各糸ごとに色・線種・太さ・リアリスティック素材を独立して設定できます。

dimensions / 糸長の推定
cm
表示値は3Dモデルの経路から求めた幾何学的な糸長です。結び代、針に残す長さ、締め込みによる増減などの作業余長は含みません。
準備完了
再生すると、①手まり芯 → ②地割り → ③かがり の順に制作工程を表示します。
操作：ドラッグ＝回転、Shift＋ドラッグ＝平行移動、ホイール＝拡大縮小。タイムラインはクリック／ドラッグで任意工程へ移動できます。
工程は ①手まり芯 → ②地割り → ③かがり。Simple / C8 / C10 の地割り順は TemariKai の公開手順を基準にしています。「原典順序トレース」のかがりは、参照ページに明記された順番・点番号・反復順を工程化しています。TemariKaiの画像や文章そのものは収録していません。
